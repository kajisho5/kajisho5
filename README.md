## Featured

### [ffmpeg-skill](https://github.com/kajisho5/ffmpeg-skill) — ★2.7k+
A local video editor for coding agents: 42 typed FFmpeg tools with a machine-readable contract, a contract-derived MCP server, and a probe → edit → check → verify workflow. Captions and karaoke, loudness (EBU R128), HDR→SDR, LUTs, sync with drift correction, multicam, delivery checks, project rendering and batch processing. No API keys, no cloud, Python standard library only.
